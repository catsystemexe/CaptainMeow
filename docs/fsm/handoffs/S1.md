- FSM schema v1

- preset metadata, source a schema version
- graph, state, movement, targeting, combat, lifecycle, transition a condition typy
- descriptor katalog
- `ParamSpec`

- cull-anchor capability validation
- strukturální, referenční a sémantická validace
- explicitní normalizace numerických hodnot
- immediate/timeless/timed cycle classification
- focused smoke test

## Important decisions

- S1 je aditivní a nenahrazuje legacy runtime FSM typy.
- Movement base je zatím reprezentovaný jako:
  - `{ type: "movementPreset", params: { presetId } }`
- Runtime validace importovaných dat není nahrazena TypeScript typy.
- Validace nemutuje vstup.
- Normalizace vrací nový objekt a explicitní `normalized` issue.
- Numerické hodnoty se nesmí skrytě clampovat pouze za runtime.
- `unknown` nebo type erasure jsou izolované na registry boundary.
- `moduleAnchor` vyžaduje `getCullAnchorX`.

## Validation semantics

- `E_PARAM_RANGE` pro hodnoty mimo rozsah při validaci.
- `N_PARAM_CLAMPED` při explicitní normalizaci.
- `E_IMMEDIATE_CYCLE` pro garantovaný okamžitý cyklus.
- `W_TIMELESS_CYCLE` pro potenciálně oscilující cyklus bez pozitivní časové hranice.
- timed cyklus není chyba.
