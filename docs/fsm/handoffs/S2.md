Implementovat čistou migraci legacy built-in FSM grafů do schema v1, validovaný immutable resolved preset model a built-in registry bez přepnutí gameplay runtime na nový systém.

- explicitní převod legacy `despawn` konvence
- resolved FSM preset
- immutable built-in registry
- dev/CI fail-fast policy
- production fail-soft policy
- integrace registry do content loaderu
- zachování legacy `BEHAVIOR_GRAPHS`
- focused migration a built-in-content smoke testy

## Legacy source

```text

```

```ts
Record<string, BehaviorGraph>
```

Legacy runtime shape remains:

```ts
BehaviorGraph = {
  initial: string;
  states: Record<string, BehaviorState>;
}
```

## Legacy-to-target mapping

### Preset

- legacy graph key → target preset ID
- source → builtin

### States

- legacy state key → stable generated `FsmStateId`
- original state key preserved as human-readable label

### Movement

```text
movementPresetId
→
movement.base = {
  type: "movementPreset",
  params: {
    presetId
  }
}
```

Missing movement may map to canonical `none.hold` only when it exists in injected known presets.

### Combat

Present `attackProfileId`:

```ts
{
  mode: "profile",
  profileId,
  runtimePolicy: "reset"
}
```

Absent `attackProfileId`:

```ts
{
  mode: "inherit"
}
```

This preserves the confirmed legacy fallback to enemy-definition attack profile.

### Targeting

```ts
{ type: "forward" }
```

### Lifecycle

Legacy state named exactly `despawn` with no outgoing transitions:

```ts
{
  enterActions: [
    { type: "despawn" }
  ]
}
```

S2 pouze reprezentuje tuto action. Nevykonává ji.

### Conditions

- `timeInState.seconds` → `timeInState.params.seconds`
- `hpBelow.ratio` → `hpBelow.params.ratio`
- `xLessThan.x` → `screenXBelow.params.x`
- `offscreen.side` → `offscreen.params.side`
- legacy offscreen margin → `marginPx: 96`

## Deterministic state-ID algorithm

- trim
- lowercase
- non-alphanumeric runs → `_`
- remove leading/trailing `_`
- empty slug → `state`
- collisions → `_2`, `_3`, etc.
- collision ordering follows canonical source order

Example:

```text
"A B" → "a_b"
"a-b" → "a_b_2"
"!!!" → "state"
```

## Immutability strategy

- resolved definitions are frozen
- resolved states are frozen
- transitions and arrays are frozen
- mutable maps remain private inside closures
- callers do not receive mutable registry maps
- canonical legacy input is not frozen or mutated

## Error policy

### Development and CI

Default policy:

```text
throw
```

Invalid built-in preset fails with preset ID, issue code and path.

### Production

Policy:

```text
omit-invalid
```

- invalid preset omitted
- valid presets preserved
- one aggregated warning per registry build

## Risks and required inputs for S3

- `combat.mode === "inherit"` zůstává závislé na enemy-definition runtime kontextu.
- S3 má používat `ResolvedFsmPreset` a state indexes, ale zachovat legacy behavior parity.
- S3 nesmí vykonávat `despawn`; to patří až do S6.
- `movementPreset` zůstává bridge do S5.
- Missing movement mapování na `none.hold` musí zůstat explicitní a validované.
