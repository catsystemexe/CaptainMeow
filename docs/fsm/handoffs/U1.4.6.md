# U1.4.6 — State formation/speed runtime wiring and side-panel fixes

## Scope

U1.4.6 continues the U1.4 FSM branch after U1.4.5. It does not start U1.5 and does not change Simple or Smart behavior modes.

## Formation data migration

The canonical state model is now:

```text
formationId
spacing
elasticity
speedMultiplier
```

Legacy states with `formationOverride` are still read by authoring and runtime resolution. Loading a legacy preset normalizes the draft view from Basic Setup/legacy values without mutating persisted storage. Edits and Save write canonical state fields and remove `formationOverride` from edited state data.

## Runtime solution

Group anchor FSM updates now apply the active state's formation data to the existing `EnemyGroupRegistry` group. The group id, member refs, and count are preserved. Member offsets are recomputed in place, so cohesion moves existing members toward the new targets. No members are respawned.

## Speed strategy

FSM speed remains centralized in the existing velocity normalization model:

```text
effectiveSpeed = basicSetup.baseSpeed × state.speedMultiplier
```

`EnemySystem` remains the single-enemy final velocity writer, and `EnemyGroupRegistry.updateAnchors()` remains the group-anchor final velocity writer. The fix changes only the data read by `fsmEffectiveSpeed()` so canonical state fields and legacy `formationOverride` fields both work. Movement direction/pattern and Hold/no-target behavior are preserved.

## Side-panel architecture

The compact preset side panel keeps fixed positioning and now has a viewport-safe max height that can show 20 consistent 26px rows before scrolling when the viewport is tall enough. The button click owns opening immediately, including the first click after Enemy Lab opens.

Runtime Diagnostics is mounted once at document body level. It is positioned as a fixed side panel to the left of the STATES area, flips right when there is insufficient left-side space, has its own scroll/viewport constraints, closes via the toggle or Escape, and repositions on resize. It continues to use the existing refresh timer and `findLatestFsmRuntimeDiagnostics` correlation.

Not performed in this non-interactive environment. Browser handoff checklist:

2. Basic Speed 80 then Spawn, Basic Speed 160 then Spawn shows visibly higher runtime speed.
3. Speed × 0.5 shows approximately half runtime speed.
4. First click on Presets immediately opens the preset side panel.
