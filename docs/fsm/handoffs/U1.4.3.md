# U1.4.3 — Polish FSM LAB controls and spawn current draft

## Goal

Polish the U1.4 FSM LAB state editor interactions and make the main Enemy Lab FSM `SPAWN` path use the current unsaved draft graph together with the draft Basic Setup. Simple and Smart behavior were intentionally not changed.

## Root cause of non-functional Delete

State deletion was only available through the legacy bottom state action row and confirmation-driven selected-state action. The focused U1.4 inline row workflow had moved practical row operations into the state list, so Delete was not directly wired per row and was effectively unavailable in the intended browser path. The model also allowed the UI to ask for deletion without first enforcing the one-state minimum at the model boundary.

U1.4.3 adds row-level Delete buttons, blocks built-ins through the existing read-only model contract, blocks one-state deletion in the model, then reconciles selected/expanded state after deletion.

## Trigger stepper

The expanded state editor now uses compact trigger steppers for sequential trigger params:

- `Time`: minus/value/plus, step `0.25`, minimum `0`.
- `scrX`: minus/value/plus, step `10`, minimum `0`.
- `Hit`: compact placeholder stepper using step `1`, minimum `1`, while preserving the existing `hpBelow` schema representation.

Stepper buttons stop propagation so row clicks do not collapse the editor, mutate the draft through `FsmPresetAuthoringModel.setLabTrigger()`, preserve expansion, and rerender summaries.

## UI aliases

The visible trigger label `screenXBelow` is now shown as `scrX`. The runtime/schema identifier remains `screenXBelow`; no graph schema migration was introduced.

## State row icons

Each state row now exposes minimalist icon buttons directly in the row:

- Duplicate
- Delete
- Move Up
- Move Down

Icon-only buttons are given `title`, `aria-label`, disabled state, and a shared 26px sizing/style helper. Core actions are no longer hidden behind the old ellipsis-only affordance.

## New state

The state list now renders `+ New state` immediately below the last state. It appends a valid default state, selects it, expands it, normalizes sequential links, and marks the draft dirty. The older duplicate bottom `Add state` action row is hidden from the visible FSM LAB path.

## Built-in immutability

Built-in presets remain read-only. Row Duplicate/Delete/Move and `+ New state` are disabled for built-ins by the existing `FsmPresetAuthoringModel.readOnly` contract. Editing a built-in still requires duplicating it into a user preset first.

## Why SPAWN used the saved graph

The main Enemy Lab FSM spawn path emitted only `fsmPresetId`, so `SpawnSystem` resolved the graph from the persisted combined FSM registry. The separate Preview Draft path already had an ephemeral resolved draft override, but normal SPAWN did not pass that override and therefore mixed current Basic Setup controls with the saved graph.

## New draft SPAWN source of truth

Manual FSM SPAWN now resolves the current authoring draft with the existing `resolveEphemeralFsmPreset()` infrastructure and passes `resolvedFsmPresetOverride` alongside the selected/draft preset id. The source of truth is now:

```text
draft.basicSetup + draft.graph
```

The selected saved preset remains the fallback when there is no explicit current draft override, and authored enemy defaults remain the runtime fallback in `SpawnSystem` outside Enemy Lab manual draft overrides.

## Single and group draft spawn

- `Count = 1`: `SPAWN_ENEMY` receives the current draft override and the spawned enemy runtime uses the draft graph immediately without Save.
- `Count > 1`: `SPAWN_ENEMY_GROUP` receives the same draft override; `SpawnSystem` applies it to the group anchor and passes it through to members.

Saved user preset storage is not mutated by spawning.

## Stop

The visible FSM spawn row is now:

```text
[                 SPAWN                 ] [ Stop icon ]
```

Stop marks only live enemies matching the latest Enemy Lab `devManualSpawnId` as pending kill. For grouped spawns it also removes the matching group registry record. It does not stop the game loop, does not delete unrelated enemies, and does not mutate the draft.

## Restart

The PRESETS toolbar includes a Restart icon. Restart stops the latest manual spawn and immediately clicks the same current draft SPAWN path again. It preserves selected preset, draft, dirty state, and expanded state. If there is no previous manual spawn, it simply spawns the current draft.

## Removed visible preview controls

The old visible controls were removed from the mounted FSM LAB UI:

- Preview Draft
- Preview Saved
- old Restart
- old Stop

The internal preview session and ephemeral override resolver remain because the new SPAWN path reuses that draft resolution infrastructure.

## Icon system

`package.json` already had no icon dependency. U1.4.3 uses a lightweight vanilla DOM/TypeScript Unicode icon set plus shared button styling instead of installing Lucide or another library. No additional icon package was added.
